Welche Daten verarbeitet werden

Die Lernanwendung ist so gestaltet, dass so wenig personenbezogene Daten wie möglich verarbeitet werden.

  • Ihre Eingaben in den Aufgaben (Textantworten, Auswahl in Selbstchecks, Bearbeitungsfortschritt) werden ausschliesslich lokal in Ihrem Browser gespeichert (Local Storage). Sie verlassen Ihr Gerät nicht und werden nicht an uns übermittelt. Sie können sie jederzeit selbst löschen, indem Sie die Websitedaten Ihres Browsers leeren.
  • Eingaben in den KI-Assistenten: Wenn Sie den Chat nutzen, wird der von Ihnen eingegebene Text sowie der Kontext der jeweiligen Aufgabe zur Beantwortung an unseren Dienstleister für KI-Sprachmodelle übermittelt und dort verarbeitet. Bitte geben Sie keine besonders schützenswerten Personendaten (z. B. Gesundheits-, Religions- oder andere sensible Daten) in den Chat ein.
  • Technische Zugriffsdaten: Beim Aufruf der Seite werden durch den Hosting-Dienstleister technisch notwendige Daten (z. B. IP-Adresse, Zeitpunkt des Zugriffs, aufgerufene Seite) verarbeitet, wie es beim Betrieb jeder Website üblich und für die Auslieferung erforderlich ist.

  • KI-Sprachmodell: Infomaniak Network SA (Schweiz). Die Verarbeitung erfolgt auf Infrastruktur in der Schweiz. Es werden nur die für die Antwort nötigen Chat-Inhalte übermittelt.
